# Asset provenance

VehicleTemplate, Vehicles, Input, Variant_Offroad, and their external actor/object assets were copied from Epic's installed UE5.8 vehicle template and TemplateResources packs. They remain Epic sample/template content subject to the Unreal Engine EULA, not a new license granted by this repository.

https://www.unrealengine.com/eula/unreal

Overlanding/Maps/RedRockRun is generated by Scripts/build_red_rock.py. Its project-owned collision cube is derived from the installed engine basic cube, and the level also references engine basic shapes. Unreal Engine is required to open the project; this repository contains no engine binaries or toolchain.

Epic's buggy remains available in the template test map. The local canyon variant uses the acquired 4Runner below.

## Locally acquired Quixel cliff

Desert Western Cliff Layered XL 14, Quixel Megascans (Fab listing 23639c4c-ca70-49f1-b462-afaa454252b2). User supplied the downloaded UE high-quality package on 2026-10-08 after approving Fab licensing. Imported mesh and textures live under Content/Licensed/QuixelCliff and are excluded from Git. Raw source is under ignored .tools/assets/cliff. Scanned development maps live under ignored Content/LocalOnly. Shared maps in Content/Overlanding use original procedural sandstone and contain no Quixel references. No public redistribution of Quixel source assets has been performed.

## Toyota_4runner

This work is based on "Toyota_4runner" (https://sketchfab.com/3d-models/toyota-4runner-3afb8daa0a4a4bfea99e1af74eca1bdb) by sadiqminhas911 (https://sketchfab.com/sadiqminhas911) licensed under CC-BY-4.0 (https://creativecommons.org/licenses/by/4.0/). Acquired 2026-10-08. Local source under .tools/assets/4runner; imported assets under Content/Licensed/Toyota4Runner. Adaptation changes: forward-X orientation, separate centered wheels, fixed axle separation, and original Chaos driving/camera code. Geometry and materials remain derived from the credited model.

The prepared meshes and materials under Content/Licensed/Toyota4Runner/Prepared are distributed in Git LFS under the same CC-BY-4.0 license. Original downloaded source and the initial unsplit import remain local. This project is not affiliated with Toyota or endorsed by the model creator.
